# OpenSpec Project Initialization Design / OpenSpec 项目初始化设计

## Goal / 目标

Initialize this Rime schema repository for OpenSpec-based work and document the repository-specific agent rules.

为这个 Rime 输入方案仓库初始化基于 OpenSpec 的工作流，并记录仓库专用的代理规则。

## Scope / 范围

- Run the installed OpenSpec CLI with `openspec init --tools codex --no-animation` so the CLI owns the standard `openspec/` layout and Codex instruction files.

  使用已安装的 OpenSpec CLI 执行 `openspec init --tools codex --no-animation`，由 CLI 负责生成标准的 `openspec/` 目录结构和 Codex 指令文件。

- Add a root-level `AGENTS.md` describing the repository purpose, the `mine` default-branch workflow, safe change boundaries, and the available configuration-level verification.

  在仓库根目录新增 `AGENTS.md`，说明仓库用途、`mine` 默认分支工作流、安全变更边界以及可用的配置级验证方式。

- Keep all existing Rime schemas, dictionaries, Lua files, and prior design/plan documents unchanged.

  保持现有的 Rime 方案、词库、Lua 文件以及此前的设计/计划文档不变。

- Do not generate integrations for unrelated AI tools, add dependencies, or introduce permanent release gates.

  不为无关的 AI 工具生成集成，不新增依赖，也不引入永久性的发布门禁。

- Write all initialization documents in bilingual English-first format: place the English description before its Chinese counterpart, while keeping commands, paths, and code unchanged.

  所有初始化文档均采用英文在前的双语格式：英文描述放在对应中文之前，命令、路径和代码保持不变。

## AGENTS.md Content / AGENTS.md 内容

The file will state that this repository contains Rime schemas and dictionaries, that changes should target the `mine` branch, that configuration edits must remain scoped and preserve custom overrides, and that validation should use focused fragment assertions plus `git diff --check` with the repository's CRLF handling. It will also point contributors to the OpenSpec instructions generated by the CLI.

文件将说明本仓库包含 Rime 方案和词库，变更应以 `mine` 分支为目标，配置编辑必须保持范围明确并保留自定义覆盖能力，验证应使用针对片段的断言以及适配仓库 CRLF 处理的 `git diff --check`。文件还会指向 CLI 生成的 OpenSpec 指令。

## Validation / 验证

After initialization, verify that the CLI-created files exist, `AGENTS.md` contains the agreed rules, `openspec status` or `openspec doctor` recognizes the project, and `git diff --check` reports no new whitespace errors. Confirm no pre-existing Rime files changed.

初始化后，验证 CLI 创建的文件存在、`AGENTS.md` 包含已确认的规则、`openspec status` 或 `openspec doctor` 能识别项目，并确认 `git diff --check` 没有报告新的空白错误。同时确认没有现有 Rime 文件被修改。
